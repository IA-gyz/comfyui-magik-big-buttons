# ComfyUI Magik Big Buttons

Big-button UI widgets for [ComfyUI](https://github.com/comfyanonymous/ComfyUI).

Merged from [`comfyui-magik-knob`](https://github.com/IA-gyz/comfyui-magik-knob) and [`comfyui-magik-toggle`](https://github.com/IA-gyz/comfyui-magik-toggle).

## Nodes

- **Magik Knob Int** (`MagikKnobIntNode`) — a large integer widget rendered as a rotary knob, vertical slider, or horizontal slider, with selectable themes and shapes.
- **Magik Toggle** (`Magik.Toggle`) — a large resizable boolean toggle with customizable on/off colors, style, and text.

## Installation

Clone into ComfyUI's `custom_nodes` directory and restart ComfyUI:

```bash
git clone https://github.com/IA-gyz/comfyui-magik-big-buttons.git
```
